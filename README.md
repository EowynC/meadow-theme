# Meadow Theme

A calm, botanical dark theme for Visual Studio Code.

Meadow combines a deep forest-green background with muted wildflower
colours to provide strong syntax separation without the harshness
of neon-heavy themes.

---

## Designed for focused development

Meadow is designed around a simple idea:

> Code should be colourful enough to understand at a glance,
> without becoming visually exhausting.

The palette takes inspiration from meadows and wildflowers:

- Sage greens for comments and secondary information
- Lavender for keywords and control flow
- Dusty rose for markup and strings
- Cornflower blue for types and symbols
- Buttercup gold for methods and numbers

The result is a dark theme with clear semantic separation while
remaining comfortable for long coding sessions.

---

## Built with .NET and Blazor in mind

Meadow was created with modern .NET development in mind, with
particular attention to:

- C#
- Razor
- Blazor
- HTML
- CSS
- JSON
- SQL

C# and Razor receive deliberately different visual treatments so
that switching between code and markup remains easy to follow.

---

## Colour philosophy

| Role | Colour |
|---|---|
| Background | Deep Meadow |
| Keywords | Lavender |
| Types | Cornflower |
| Methods | Buttercup |
| Strings | Poppy |
| HTML | Wild Rose |
| Attributes | Ochre |
| Comments | Sage |

The colours are intentionally muted rather than neon, keeping the
palette distinctive without overwhelming the editor.

---

## Current status

Meadow is currently in early development.

The colour palette and semantic highlighting are still being refined,
particularly around Razor and C# syntax.

Feedback and suggestions are very welcome!

---

## Installation

Search for **Meadow** in the Visual Studio Code Extensions view,
or install it directly from the Marketplace.
